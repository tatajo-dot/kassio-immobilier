# KASSIO IMMOBILIER

Application privée des résidents KASSIO IMMOBILIER (PWA), créée à partir d'une copie d'ADRESS CLUB.
Elle est entièrement séparée d'ADRESS CLUB : autre dépôt, autre base Supabase, autre adresse web.

## Publier une nouvelle version

1. Modifier les fichiers.
2. Dans `sw.js`, changer `CACHE` (`kas-v1` → `kas-v2`…) : c'est ce qui fait télécharger la nouvelle version aux téléphones.
